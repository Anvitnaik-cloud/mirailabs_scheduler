# Coordinator Dashboard (Phase 5)

React frontend application for real-time placement week coordination, conflict visualization, and one-click disruption replanning.

## Planned Architecture
- Vite + React + TypeScript
- CSS Modules / Vanilla CSS design tokens (dark mode & high-contrast layout)
- Interactive schedule grid view (by Room, by Company, by Student Timeline)
- Live Disruption Injector & Diff Inspector (`moved`, `cancelled`, `newly_scheduled`, `who_to_notify`)
